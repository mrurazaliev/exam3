# Catalyst Analytics — Digital Solutions Website

Адаптивный веб-сайт для компании **Catalyst Analytics**, специализирующейся на решениях в сфере искусственного интеллекта (AI), машинного обучения (ML), блокчейна и аналитики данных.

## 🚀 Стек технологий

* **HTML5** — семантическая структура страниц.
* **Tailwind CSS** — утилитарный фреймворк для быстрой и гибкой стилизации.
* **Компонентная графика (SVG)** — легковесные векторные иконки.

---

## 📂 Структура страниц проекта

Проект разбит на несколько ключевых страниц для демонстрации различных разделов платформы:

1.  **Главная страница (Home / Page1.html)**
    * Главный экран (Hero Section) с презентацией бренда.
    * Интеграционная карусель/сетка с карточками клиентов (100+ компаний).
    * Краткий обзор ключевых услуг компании.
    * Раздел часто задаваемых вопросов (**FAQ**) с аккордеон-структурой.
2.  **Услуги (Services / Page2.html)**
    * Подробный каталог цифровых решений (ML Solutions, Blockchain, Algorithmic Trading и др.).
    * Интерактивные списки преимуществ для каждого направления.
3.  **Карьера (Careers / Page3.html)**
    * Панель фильтрации вакансий (по департаментам, опыту, типу работы).
    * Сетка актуальных открытых позиций (Web Designer, Mobile Developer, Project Manager).
4.  **Контакты (Contact / Page5.html)**
    * Двухколоночная интерактивная форма обратной связи «Send Us a Message».
    * Блок с прямой контактной информацией (Email, Телефон, Физический адрес).
    * Форма быстрого бронирования бизнес-встреч (Book a Meeting).

---

## 📱 Особенности верстки

* **Mobile-First & Responsive:** Сайт полностью адаптирован под мобильные устройства, планшеты и большие мониторы (используются брейкпоинты `md:`, `lg:`).
* **Pixel Perfect Form:** Секции форм (включая Cloudflare-капчу и выбор кода страны) сверстаны в строгом соответствии с дизайн-макетами из Figma.
* **Dark Mode Style:** Дизайн выполнен в современной глубокой темной палитре (`bg-black`, `bg-[#111111]`) с контрастными синими акцентами (`#0A84FF`).
